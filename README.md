# My Android Tablet launcher

![The launcher running on a Boox Go 10.3](artwork/tablet-launcher-hero.png)

A custom launcher I built for my Boox 10.3 Go. I found the default one too complex. I needed a simple "pick up tablet -> open app" launcher instead of digging through menus.

This is a launcher for my Android e-ink tablet. It is designed for low-latency e-ink screens.

---

## Run

Install the debug app on a connected Android device:

```shell
./gradlew :androidApp:installDebug
```
